# Roadmap

## Next: statement imports

- CSV/XLSX upload validation and configurable column mapping.
- Deterministic import identity and duplicate preview.
- Transactional import with import history and row-level errors.
- Explicit internal-transfer matching and manual transfer entry.

## Later

- Account balance reconciliation workflow.
- Search and filters for larger transaction histories.
- Export/backup tools.
- Regulated EU Open Banking aggregator adapter feeding the same canonical
  transaction pipeline. No direct bank credential handling.
- Android notification adapter.

React Native is intentionally deferred until the web workflow is proven.
